# Roots & Shoots Event Flyer

🌿 A modern, multilingual event flyer for Roots & Shoots capacity building sessions.

## Features

- 🌍 **Multilingual** – English, French, Kiswahili
- 🌓 **Dark/Light mode** – user preference saved
- ⏱️ **Live countdown** to event
- 📋 **Copy to clipboard** – Zoom link, Meeting ID, Passcode
- 📱 **Fully responsive** – works on all devices
- 🖨️ **Print-friendly** – A4 ready
- 🎨 **Glass-morphism** design with animated elements

## Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. Edit `flyerData` object in `script.js` to customize content

## Customization

Edit the `flyerData` object in `script.js`:

```javascript
const flyerData = {
  organization: "Roots & Shoots Global",
  title: "Capacity Building",
  subtitle: "Extra Ordinary COP Call",
  speaker: "Rita Groenewald",

  time: "16:00 EAT",
  meetingID: "863 4323 1368",
  passcode: "634051",
